# Jeremy Personal Site Redesign Plan

## 1. Current State

The current public site is a Notion-based personal homepage:

- Hero intro: marketing specialist in Shanghai, with personal interests and contact details.
- Content area: article collections about Japan, marketing, design, and essays.
- Media area: Bilibili videos and podcast episodes.
- Visual area: photography and Instagram.
- Resource area: a Notion database called `信息源`.
- Contact area: social links and newsletter signup.

This means the site already has strong raw material, but it is organized as a content shelf, not as a clear professional system.

## 2. Core Redesign Direction

The redesign should not be "make the current site prettier."

It should change the framing from:

- who I am
- what I posted
- where to find me

to:

- how I think
- what I can do
- what I have proven
- how people can work with me
- how an AI version of me can be queried

The main upgrade is from `content archive` to `capability interface`.

## 3. Module Mapping

| Traditional site module | New module | What it should do |
| --- | --- | --- |
| About Me | My Operating System | Explain your thinking model, decision rules, taste, research habits, and working principles |
| Portfolio | Playground | Turn selected experience into interactive demos, breakdowns, and scenario-based capability showcases |
| Blog | Thinking Feed | Merge articles, videos, podcast notes, and source database into one tagged knowledge stream |
| Contact | Interface | Present collaboration modes, contact protocol, and external channels like an API/interface layer |
| Resume/CV | Proof of Work | Add quantified work history, project evidence, timeline, and downloadable CV |
| Skills list | Live Agent | Build an AI-facing layer that answers questions about your background, work, content, and frameworks |

## 4. Recommended Site Structure

Recommended order for the new homepage:

1. Hero
2. My Operating System
3. Proof of Work
4. Playground
5. Thinking Feed
6. Interface
7. Live Agent

This order is better than following the old format because it establishes:

1. identity
2. credibility
3. capability
4. ongoing thinking
5. collaboration path
6. interaction layer

## 5. Section-by-Section Plan

## 5.1 Hero

The current hero says you are a marketing specialist in Shanghai. That is too generic.

The new hero should position you as a hybrid profile:

- media strategist
- cross-cultural researcher
- content system builder
- AI-era operator

Recommended hero formula:

`I design media systems, content strategy, and research-driven brand communication.`

Supporting line:

`Based in Shanghai. Working across marketing, Japan studies, audience insight, and AI-native workflows.`

Hero actions:

- View Proof of Work
- Explore Thinking Feed
- Talk to Live Agent

## 5.2 My Operating System

This replaces the old About section.

It should not be a life story. It should explain how you process the world.

Suggested blocks:

- Inputs: Japan, marketing, design, photography, platform culture, consumer behavior
- Processing model: research -> framing -> channel strategy -> content adaptation -> measurement
- Working principles: audience-first, media-fit, context sensitivity, measurable outcomes
- Tool stack: Telmar, Kantar, QuestMobile, SEO platforms, ad platforms, research workflow, AI tools
- Personal edge: bilingual and cross-cultural synthesis, editorial taste, strategy plus execution

Suggested headline:

`My Operating System: how I observe, decide, and execute`

This section should make a visitor feel:

- this person has a method
- this person is not only a content hobbyist
- this person can translate culture into strategy

## 5.3 Proof of Work

This is the missing section and should become one of the strongest parts of the site.

It should be built from your resume, but not shown as a plain CV dump.

Recommended structure:

- Snapshot
- Career Timeline
- Selected Cases
- Capability Evidence
- Download CV

Use a concise summary card:

- 7+ years in media planning and communication
- Industries: gaming, retail, apparel, FMCG, automotive
- Managed budgets up to RMB 150M annually
- Strengths: media strategy, user insight, content optimization, integrated campaign execution

- 2023.12-2024.04: OMG / Hearts & Science, Senior Media Planning Manager
- 2021.09-2023.09: EssenceMediacom, Planning Manager
- 2021.03-2021.09: Havas, Planning Manager
- 2019.10-2021.03: Dentsu Aegis, Assistant Planning Manager

Each role should show:

- client type
- strategic responsibility
- budget scale
- measurable result

### Selected Cases

Turn resume bullets into evidence cards.

Recommended cases:

- Range Rover launch planning
- Nintendo CNY campaign
- Bicester Village acquisition campaign
- PUMA new product launch
- Iced Dew / Authentic Tea House media planning

Each case card should follow one structure:

- Context
- Challenge
- Strategy

- Result

### Capability Evidence

This is more persuasive than a skills list.

Use proof clusters:

- User insight: audience profiling, segmentation, pain-point discovery
- Media strategy: budget allocation, channel mix, platform fit
- Content optimization: KOC material, native content direction, ad copy refinement
- Performance improvement: CAC down 20%, CTR up 20%, recall up 30%, store visits up 50%, sales up 20%
- Risk and sentiment: SEO and public opinion correction, non-negative rate up 20%

### Download CV

Include:

- English PDF
- Chinese PDF
- short one-page profile for recruiters

## 5.4 Playground

This section should not be a traditional portfolio gallery.

It should demonstrate what you can do in real time or near-real time.

Because your current raw material is mostly articles, campaigns, and videos, the best Playground is a set of structured demonstrations.

Recommended items:

- Campaign teardown: show how you would dissect a brand launch
- Audience mapper: show a sample segmentation logic for one category
- Media mix simulator: show channel choices by goal
- Japan trend scan: show how you track cultural signals and translate them into ideas
- Creative brief generator: show how a messy business ask becomes a clear brief

If the site remains Notion-first, this can be a curated page with embedded demos, before building true interaction.

If the site becomes custom-built, this should become a real interactive module.

## 5.5 Thinking Feed

This section should absorb the current article, video, podcast, and information-source content.

The key redesign principle:

Do not organize by format first.

Instead, organize by idea and topic first.

Recommended top-level tags:

- Japan
- Marketing Systems
- Consumer Insight
- Design and Aesthetics
- Field Notes
- Media and Platforms

Each item should then carry a format tag:

- Article
- Video
- Podcast
- Note
- Source

This allows your old site assets to merge into one stream instead of feeling fragmented.

Recommended subsections:

- Featured essays
- Latest thinking
- Knowledge map
- Source library

The existing `信息源` database should be upgraded from a private list into a visible knowledge graph or curated reading system.

## 5.6 Interface

This replaces a weak `contact me` section.

It should feel like a protocol layer.

Recommended blocks:

- What you can contact me for
- What to send me
- Where to reach me
- Expected response style

Suggested collaboration modes:

- media strategy consultation
- campaign diagnosis
- audience and platform research
- content direction review
- partnership and speaking

Suggested copy direction:

`If you have a brand, campaign, market, or cultural problem that needs sharper framing, send context, objective, and deadline.`

Communication channels:

- email
- LinkedIn
- Telegram or WeChat if appropriate

This section can still include social links, but they should support the protocol instead of acting as the main content.

## 5.7 Live Agent

This is the most "AI/Agent era" section and should be designed carefully.

The Live Agent should answer questions like:

- Who is Jeremy?
- What kind of projects has he done?
- What does he think about Japan, marketing, or design?
- Which case is most relevant to my brand or hiring need?
- How would he approach a campaign problem?

The knowledge base should come from:

- your CV
- selected articles
- selected video transcripts or summaries
- podcast summaries
- case-study writeups
- your operating principles

Recommended V1 scope:

- Q and A about background and work
- recommended article or case routing
- ability to summarize your approach to a specific business question

Recommended guardrails:

- only answer based on uploaded materials
- distinguish between proven experience and general opinion
- route users to contact if they want collaboration

## 8. Design Direction

The design should feel more like a system dashboard or field manual than a generic personal homepage.

Recommended design traits:

- editorial and research-heavy rather than lifestyle-blog style
- strong typography
- visible structure and section jumps
- tags, cards, timelines, and proof labels
- lighter use of decorative photos; stronger use of evidence blocks
- bilingual support if possible

Tone:

- sharp
- thoughtful
- analytical
- culturally literate
- not overly corporate

## 9. Platform Recommendation

Because your current site is entirely on Notion and the local project folder is empty, there are two realistic implementation paths.

### Path A: Notion-first rebuild

Best when speed matters.

- Rebuild the page architecture in Notion
- Create databases for Thinking Feed and Proof of Work
- Use synced blocks and linked databases
- Embed simple interactive tools for Playground
- Add a third-party AI widget for Live Agent

Pros:

- fast
- low engineering cost
- easy to maintain

Cons:

- weaker branding control
- Playground and Live Agent will feel limited

### Path B: Custom site with Notion as content source

Best when the new positioning matters more than speed.

- Build a standalone frontend
- Use Notion or markdown as CMS
- Create custom layouts for timeline, proof cards, and live agent
- Keep content editing lightweight

Pros:

- much stronger identity
- real Playground interactions
- better Live Agent integration
- cleaner long-term structure

Cons:

- requires actual build work
- higher setup time

Recommended choice: Path B.

The new concept is too ambitious for a pure Notion page if you want the `AI/Agent era` framing to feel real.
